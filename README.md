# AtliQ Hardware Sales & Finance Analytics Dashboard

## Project Overview
This project provides business insights for AtliQ Hardware by analyzing sales and financial performance across customers, markets, and fiscal periods.

## Reports Included

1. Customer Performance Report
   - Customer-wise net sales analysis
   - Year-over-year growth comparison (2019-2021)

2. Market Performance vs Target Report
   - Market-wise sales performance
   - Target achievement analysis
   - Variance percentage tracking

3. P&L Statement by Fiscal Year
   - Net Sales
   - COGS (Cost of Goods Sold)
   - Gross Margin
   - Gross Margin %

4. P&L Statement by Markets
   - Market-wise profitability analysis
   - Gross Margin comparison across countries

5. P&L Statement by Months
   - Monthly sales and profitability trends
   - Year-over-year performance analysis
